# Doity Design System

Pacote Vue/Nuxt 4 com componentes, design tokens CSS e documentação sincronizada com o Figma.

## Instalação

```bash
pnpm add @arthurdoity/design-system
```

Configure o módulo:

```ts
// nuxt.config.ts
export default defineNuxtConfig({
  modules: ['@arthurdoity/design-system'],
})
```

## Uso nos componentes

Todos os componentes são registrados **globalmente** com prefixo `Doity`:

| Storybook | No seu projeto Nuxt |
|-----------|---------------------|
| `Button` | `<DoityButton>` |
| `Checkbox Group` | `<DoityChoiceOption>` / `<DoityCheckboxGroupItem>` |
| `File Dropzone` | `<DoityFileDropzone>` |
| `Select` | `<DoitySelect>` |

Exemplo:

```vue
<template>
  <DoityButton hierarchy="primary" size="md" @click="salvar">
    Salvar
  </DoityButton>
</template>
```

## Organização do menu

Os componentes ficam em **Components**, agrupados por uso:

| Categoria | Exemplos |
|-----------|----------|
| **Actions** | Button |
| **Forms** | Input, Select, Dropdown, Date Picker, Checkbox, Radio, Switch, Checkbox Group |
| **Feedback** | Alert, Sonner, Spinner, Empty, Tooltip |
| **Navigation** | Navbar, Menubar, Navigation Menu, Tabs, Breadcrumb, Pagination |
| **Data** | Table, Chart, Badge, Avatar, Card |
| **Overlay** | Dialog, Modal |
| **Upload** | File Dropzone, File Upload |
| **Layout** | Accordion |

Cada página inclui instalação, props, eventos/slots e **Show code** com o nome `Doity*`.

## Tokens

Cores, tipografia e espaçamentos vêm de CSS variables `--doity-*`.

```css
background: var(--doity-color-action-primary-default);
```
